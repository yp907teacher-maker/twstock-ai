# 台股 AI 分析與預測網站（個人研究用）

依《台股 AI 分析與預測網站 PRD v0.3》實作：台灣上市櫃普通股與 ETF 的收盤後資料更新、資料品質檢查、均衡量化評分、20／60 交易日報酬預測（含驗證與校準）、時間序列回測，以及只引用資料庫數字的 AI 研究報告。

> 本系統是個人研究輔助。評分是同組相對排序、不是上漲機率；模型預測不保證準確；不連接券商、不下單、不構成投資建議。

## 一、先看示範（不需任何金鑰）

需要 Python 3.11 以上。

```bash
# macOS：打開「終端機」，輸入 bash 加一個空格，把 start.sh 拖進視窗，按 Enter
bash start.sh demo
# Windows：雙擊 start.bat，或在命令提示字元執行
start.bat demo
```

macOS 不需要自己安裝 Python：start.sh 會自動安裝 uv 並準備 Python 3.12。

開啟 http://127.0.0.1:8000 。示範模式使用合成資料（代號 D1001、DE050 等為虛構），寫入獨立的 `backend/data/twstock_demo.db`，畫面頂端全程顯示「示範資料」橫幅，不會和真實資料混用。

## 二、使用真實資料（全部免費）

**最簡單的方式**：直接執行 `start.bat`（Windows）或 `./start.sh`（Mac），不要加 `demo`。第一次啟動會自動在背景抓真實資料：同步主檔 → 今日收盤（官方 OpenAPI，免金鑰）→ 回填歷史股價與除權息 → 計算評分、精選與模型 → 回填月營收、財報、法人 → 再計算。進度顯示在網頁右上角。沒有 FinMind token 也能跑（每小時 300 次，較慢）；填了免費 token 會快一倍。以下是手動控制的方式。

### 1. 申請免費金鑰並填入 `backend/.env`

| 用途 | 來源 | 費用與限制 | 必要性 |
| --- | --- | --- | --- |
| 每日收盤行情 | 證交所、櫃買中心 OpenAPI | 免費、免金鑰；政府資料開放授權條款第 1 版；只提供最新一期 | 必要（自動） |
| 歷史回填、財報、月營收、法人、融資融券、除權息、下市櫃 | [FinMind](https://finmindtrade.com/) | 免費註冊取 token，600 次／小時；Free 方案限非商業用途 | 必要（回測與模型需要歷史） |
| 盤中手動刷新 | [Fugle](https://developer.fugle.tw/) | 基本用戶免費，盤中 60 次／分鐘 | 選用 |
| AI 報告 | [Claude API](https://console.anthropic.com/) | 依用量計費；可設每月呼叫上限 | 選用（未設定時改用程式化摘要） |

```bash
cp backend/.env.example backend/.env   # Windows: copy backend\.env.example backend\.env
```

### 2. 初次建置資料

```bash
cd backend
python -m app.cli instruments                         # 同步上市櫃股票／ETF 主檔（含已下市標的）
python -m app.cli backfill --symbols 2330 0050 2454 --datasets prices actions   # 先回填想看的標的
python -m app.cli backfill                            # 全市場回填（可中斷，再執行會續傳）
python -m app.cli daily                               # 抓今日收盤 → 品質檢查 → 評分 → 模型 → 回測
```

**回填時間估算**：全市場約 2,400 檔，每檔「行情＋除權息」約 3 次請求、全部資料集約 8 次。以免費 600 次／小時計，只回填行情與除權息約 12 小時，全部資料集約 1.5 天。系統會記錄每檔每資料集完成到哪天，中斷後重跑會從斷點繼續；也可以在網頁「資料健康」頁設定每次最多請求數分批執行。

### 3. 啟動

```bash
./start.sh        # 或 start.bat
```

伺服器啟動後，平日台北時間 17:40 會自動執行收盤後更新（`DAILY_JOB_HOUR`／`DAILY_JOB_MINUTE` 可調）；也可在「資料健康」頁手動觸發。電腦需保持開機，或改部署在雲端主機。

## 三、放到網路上自動更新（GitHub，免費）

`.github/workflows/update.yml` 會在 GitHub 的伺服器上執行：平日 17:40 抓收盤資料，另外每 3 小時分段回填歷史資料，計算評分、精選、模型與回測後，把結果發佈成 GitHub Pages 唯讀網站。

1. 在 GitHub 建立公開 repo，推上本專案。
2. Settings → Pages → Build and deployment → Source 選 **GitHub Actions**。
3. Settings → Secrets and variables → Actions → New repository secret：名稱 `FINMIND_TOKEN`，值為 FinMind 免費 token（強烈建議；未設定時共用 IP 容易被限流）。
4. Actions → 「每日更新台股資料與網站」→ Run workflow 先跑一次。

說明：資料庫存在 Actions 快取（不公開）；網站內容（價格、評分）為公開。全市場歷史回填需要多次排程（約 1–2 天）才會完整，期間評分只涵蓋已回填的標的。若證交所 OpenAPI 擋海外 IP，「資料健康」頁會顯示失敗。

## 五、方法摘要

**資料原則**：行情保存未還原原始價，另存還原因子（除權息、減資的參考價比例）；每筆資料保存 provider、retrieved_at、source_updated_at（來源未提供則為空，不偽造）。月營收以次月 10 日、季報以法定期限（5/15、8/14、11/14、隔年 3/31）作為可用日，回測只能使用可用日之後的資料。缺值一律保留為缺值，不以 0 代替。

**資料品質（FR-03）**：非交易日、價格邏輯、重複、缺開高低、異常跳動（非除權息日超過漲跌幅）、筆數驟降、個股缺漏交易日、資料過舊。錯誤等級問題會讓該標的不產生正式分數與預測。

**量化評分（PRD 第 9 節）**：趨勢 30%、基本面 25%、流動性 15%、籌碼 15%、估值與風險 15%（初始假設，未依回測調整）。特徵在同日同組內轉為百分位；缺失分項的權重重新正規化並揭露覆蓋率（低於 60% 不排名）。ETF 不套用企業財務分項；槓桿／反向 ETF 另組排名。硬性排除：歷史不足 120 日、同組流動性後 20%、資料品質錯誤、手動停用、已下市。本益比不是越低越好：中低分位最佳，極高與極低都扣分。

**預測模型（PRD 第 10 節）**：目標為未來 20／60 交易日含息總報酬。梯度提升模型，特徵為同日同組百分位。時間順序切分：前 80% 日期做 walk-forward 驗證，最後 20% 為最終測試集（不用於調參），訓練與測試之間保留 horizon 長度間隔防止標籤重疊。與零報酬、歷史平均、簡單動能三個基準比較；只有 Rank IC > 0.02、高於動能基準、t 值 > 2，且 MAE 不劣於基準時，才標示「優於基準」。80% 預測區間以 conformal 方法校正並檢驗實際覆蓋率；上漲機率經 isotonic 校準，Brier 未比基準率改善 1% 以上或 ECE ≥ 0.05 時不顯示。每週五（或無模型時）重訓，預測快照不覆寫，結果成熟後回填實際報酬。

**回測（FR-08）**：每 20 個交易日再平衡，訊號於收盤後產生、下一交易日開盤成交，等權持有前 10 名。成本：手續費 0.1425% × 折扣（預設 6 折）、證交稅股票 0.3%／ETF 0.1%、滑價 0.1%；另做無折扣、滑價 0.3% 的高成本壓力測試。宇宙包含已下市標的。

**AI 報告（PRD 第 11 節）**：只把資料庫中的評分、特徵、模型輸出與時間戳交給 Claude，固定輸出摘要、支持證據、反向證據、預測情境、主要風險、資料完整度。輸出中的每個數字都會比對輸入資料，對不上就改用程式產生的量化摘要。同一資料版本只生成一次並快取；超過每月上限自動降級。

## 六、上線前需要你實測確認的事項

這些在開發環境無法連線驗證，程式已做寬鬆解析與錯誤紀錄，但第一次執行後請到「資料健康」頁檢查：

1. **櫃買中心 OpenAPI 欄位名稱**（`tpex_mainboard_daily_close_quotes`）：依政府開放資料平台說明實作，若改版導致缺欄，該批資料會被拒絕寫入並記錄錯誤。
2. **證交所 STOCK_DAY_ALL 的「漲跌」欄位**：每日除權息以「收盤 − 漲跌 = 參考價」推算，需確認正負號格式；推算結果標記為「推算除權息（待校正）」，可再用 FinMind 回填 `actions` 校正。
3. **FinMind 財報為單季或累計值**：近四季 EPS、ROE 以單季值加總計算；若實際為累計值，需調整 `features.py`。
4. **債券 ETF 證交稅免徵優惠到 2026/12/31**：之後是否延長請再查；回測目前對所有 ETF 保守採 0.1%。
5. 流動性門檻、資料完整率 99%、18:00 更新 SLA 等仍是 PRD 的初始假設，需以實際資料分布校準。

## 七、專案結構

```
backend/
  app/
    config.py            設定（.env）
    models.py            資料表（對應 PRD 資料字典）
    sources/             官方 OpenAPI、FinMind、Fugle、示範資料
    pipeline/            匯入、品質檢查、特徵、評分、預測、回測、AI 報告
    api/main.py          FastAPI + 前端靜態檔
    jobs.py / cli.py     工作排程與命令列
    static/              建置後的前端
  tests/                 單元與端到端測試（python -m pytest）
frontend/                React + Vite 原始碼（npm install && npm run build）
```

修改前端後執行 `cd frontend && npm install && npm run build`，輸出會直接覆蓋 `backend/app/static`。開發時可 `npm run dev`（自動把 /api 轉到 :8000）。
